dotz

在你自己的电脑上一直运行的个人助理。

它读新邮件、写好回复草稿，然后等你在手机上点发送。

curl -fsSL https://raw.githubusercontent.com/ddotz/dotz/main/install.sh | sh
  1. 以管理员身份打开 PowerShell，运行 wsl --install。
  2. 重启后，把上面的命令粘贴到 Ubuntu 窗口里。
  3. dotz 在 WSL 里运行，并从那里操作 Windows。安装说明（韩文）

试用演示 在 GitHub 上加星

演示和网页应用的界面目前是韩文。

怎么用

  • 回邮件，确认一下就行

    dotz 读新邮件，用你的语气写好草稿。觉得没问题，点发送就好。

  • 在手机上问一句

    不在电脑前，也能用常用的聊天软件问今天的日程或邮件。

  • 降价不错过

    选好要关注的商品，价格一降，手机上就会收到通知。

有什么不同

  • 在你的电脑上运行

    直接使用这台电脑上已有的登录状态和文件，密钥保存在 ~/.dotz/secrets。

  • 不经你同意，什么都不发

    邮件、回复和帖子都会留在聊天里，等你批准。

  • 每个项目一个会话

    因重启或断网中断的工作会自动接着做完。

  • 能找回以前的对话

    像“上周那个”这样随口一问也行。建索引和搜索都只在这台电脑上进行。
